User guides and screenshots for WPF, Tui and Web are regenerated by test runs of user journeys and land beside the app docs (`docs/applications/{app}/user-guide`). API guides are built from OpenAPI, AsyncAPI and ksy files by deterministic MSTest scripts (`npm test` for JavaScript). JavaScript and TypeScript projects are `.esproj` so Visual Studio and the build pipeline manage them.

**Why:** owner (2026-10-30) wants documentation as self-maintained as possible; hand-edited guides go stale.

**How to apply:** design in `docs/design/GeneratedGuides/`; see [[feedback-commit-user-guides]] and [[feedback-migration-docs-pattern]]. Owner also approved rules, skills and hooks that make the work better.
