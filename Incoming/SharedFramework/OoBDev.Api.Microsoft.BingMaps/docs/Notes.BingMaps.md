# OoBDev - Microsoft Bing Geocoding Services

## Summary

This library adds support for OoBDev.SpatialServices to use US Census data for GeoCoding.

## Configuration Options

| Key                           | Usage                                                      | Default     |
| ----------------------------- | ---------------------------------------------------------- | ----------- |
| Microsoft:BingMaps:ApiKey     | API Key for Bing API Mapping Services                      |             |
