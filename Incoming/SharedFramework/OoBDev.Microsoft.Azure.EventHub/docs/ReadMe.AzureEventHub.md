# OoBDev - Azure Event Hub Integration

## Summary

This may be used to use Azure Event Hub for processing complex business events

## Configuration

| Key                                     | Notes                                                |
| --------------------------------------- | ---------------------------------------------------- |
| Azure:EventHub:Default:ConnectionString | Azure Event Hub Connection String                    |
| Azure:EventHub:Default:DefaultHubName   | Azure Event Hub name                                 |
| OoBDev:EventHubProvider:Type         | Set to AzureEventHubProvider to enable this provider |
