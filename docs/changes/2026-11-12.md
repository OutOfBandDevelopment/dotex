## HTML template directives

- `OoBDev.System.Text.Html` now applies the `value-of`, `repeater`, `condition`, `value-attr` and `data-binding` directives (owner decision 2026-11-11), ported from the owner's TextTemplating project with its template semantics: nested scopes through `item` and `source`, `$` root paths, JSONPath-style filters, rules and date or number formats.

## Playback checkpoints

- `SessionLogger` writes a marker-only `checkpoint` record after every 500 received chunks (`checkpointEvery`; 0 turns it off). Older readers keep it as an unknown record and playback text skips it.
- New optional `ISnapshotPresenter` (`Snapshot()`, `Restore(object?)`), implemented by the ASCII, key-value, hex, binary, decimal and octal presenters; `Pipeline.TakeSnapshot` and `RestoreSnapshot`. `Utf8Presenter` followed later the same day (see below).
- `PlaybackEngine` takes the snapshot when it plays a checkpoint and, on a backward seek, restores the nearest earlier one and replays only the records after it. Per-record outputs are cached so the reset batch still holds the whole transcript; `AddNote` and `ChangePipeline` drop stale cache entries.
- Design: `docs/design/SessionLogging/session-logging.md`. Tests: 9 new Unit tests (`PlaybackCheckpointTests`) plus the existing logging tests pass (53 in the filtered run).

## DevTerm TCP services

- `ServiceHostBridge` (DevTerm.Core, an `IDeviceAdapter`) hosts the echo, discard, daytime, time or chargen server so a session shows what clients send; the server's replies surface on `Replied`, and anything typed in the session is dropped because the service decides its replies. It binds loopback by default, and a port that cannot be bound throws an `IOException` naming the address.
- `ServerBase` gained a `Traffic` tap (bytes plus direction; a throwing observer is ignored) and a protected `SendAsync` that the echo, daytime, time and chargen servers now use. `DisposeAsync` no longer rethrows the cancellation and socket errors that stopping causes. `ChargenServer` takes `maxBytesPerClient` (default 64 KiB, 0 for no limit).
- CLI: `--transport service --service <echo|discard|daytime|time|chargen> [--port N] [--host ip]`, validated, described and added to the connection editor and the profile schema.
- Design: `docs/design/DevTermParity/generic-services-plan.md`. Tests: 8 `ServiceHostBridgeTests` plus validator tests (Core Unit run: 1101 passed, 5 skipped).

## Utf8Presenter snapshot

- `Utf8Presenter` now implements `ISnapshotPresenter`: it tracks the incomplete multi-byte tail itself (the `Decoder` hides it) and rebuilds the decoder from it on `Restore`, so a pipeline with the UTF-8 presenter seeks backward from a checkpoint instead of replaying from the start.
- Design: `docs/design/SessionLogging/session-logging.md` (limit paragraph updated). Tests: 4 new `Utf8PresenterTests` (mid-character, boundary, snapshot immutability, foreign snapshot); with the checkpoint tests 16 passed.
