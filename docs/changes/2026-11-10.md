## Plugin sandbox: binary frame protocol and lifetime design

- The spike wire is now a packed binary frame (`FrameChannel`): versioned 32-byte header (flags, type, payload format, length, sequence, ack, topic length, hops, ttl), topic, payload (opaque; may be a JSON string), optional CRC-32 and HMAC-SHA256 with counter-signed replies. 22 Unit tests pass. Design updated in `docs/design/PluginSandbox/` (protocol layout and violations, threat model, API, testing). New design for REQ-011: lifetime `Bound` or `Shared` (named mutex, reusable) and `onCallerExit` `Kill` or `Survive` with a reconnect window; designed only, not built. The AppContainer launcher is written but untested; CPU, process and wall-time limits and escape tests are still missing, and Linux is not addressed.

## Plugin sandbox: AppContainer isolation and limits proven by escape tests

- The Must scope that the first spike left out is now built and tested on Windows (REQ-001 files and environment, REQ-005 memory, CPU, wall and process count, REQ-007 no network by default): `SandboxedPlugin` runs the plugin in an AppContainer inside a job object; `EscapeTests` has 9 Integration tests, each refusal paired with a positive control. 31 tests in the project pass (19 frame Unit, 3 earlier Integration, 9 escape).
- Findings are in [spike-result](../design/PluginSandbox/spike-result.md): `CreateProcessW` needs `LOCALAPPDATA` in an explicit environment block (and a sorted block), the launcher keeps its own process handle, the runtime's GC limit makes the memory kill land near 73%.
- Not built: Linux (REQ-008), per-host network grants, signed packages, the broker, the lifetime modes (REQ-011) and the request context (REQ-012). Their designs are in `docs/design/PluginSandbox/`.

## Plugin sandbox: bound and shared lifetimes

- `PluginPool` leases a plugin as Bound (own instance, ended on dispose) or Shared (keyed by plugin id plus grant hash, ended by an idle `Sweep`), with `PluginLease`, `PluginLifetime` and `SandboxedPlugin.ProcessId`. 6 Unit tests and 3 Integration tests (real AppContainer process gone after dispose or sweep). Not built: cross-process named mutex, a caller-death kill test, Survive/reconnect. Design: [requirements](../design/PluginSandbox/requirements.md) REQ-011.
