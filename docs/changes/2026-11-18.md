# Changes 2026-11-18

Work finished on 2026-11-18, one section per task. Index: [README](README.md).

## Metadata query: buckets shape

- `OoBDev.Query.Metadata` gains shape `buckets` (grid cells over two numeric facets with a `Cell` size, `Sample` expression on the kind, `Bucket` row, `IQueryDialect.GridCell`, text form `as buckets by a,b cell n`, OpenAPI shape enum); the PostgreSQL dialect implements `GridCell`. Unit tests: 7 added (56 passed); Integration: one added against the pgvector service (19 passed). Hints, relations and graph shape remain in the second slice, so the request stays open. [Design](../design/MetadataQuery/README.md).
## Metadata query: hints

- `[Hint]` on a kind and `select: ["has"]` give each row a `has` object of boolean flags, computed by one batched statement for the page keys (the look-ahead row is excluded). `KindInfo.Hints`, `KindDescription.Hints`, `has` in the OpenAPI row schema, `RowMapper` maps the flag dictionary to the row class `Has` property. Unit tests: 4 added (60 passed); Integration: one added (20 passed against pgvector). Relations and graph shape remain, so the request stays open. [Design](../design/MetadataQuery/README.md).
## Metadata query: relations

- `[Relation]` on a kind plus `related { via, of }` (text: `of via:key`) selects the rows related to one anchor row; the anchor is bound, the condition joins the filters so paging and count work as before. Unit tests: 5 added (65 passed); Integration: one added (21 passed against pgvector). Graph shape, snapshot sources, near spaces and the host sample remain, so the request stays open. [Design](../design/MetadataQuery/README.md).
