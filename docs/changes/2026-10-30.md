## DevTerm WPF device panels (2026-10-30)

WPF slice 5, first part: `SurfacePanelBuilder` (DevTerm Core, `Panels`) turns a plugin's `UiDefinition` and its `IControlSurface` into a form-ready `SurfacePanel`, using a generated model (`DynamicModelFactory`) as the SCPI panels do (Q4 option C, no Framework change). Toggles, sliders, numbers, choices and text fields send their value to the surface when it changes (toggle as "1"/"0"); a button is an `ICommand` that sends `CommandId ?? Id`. Indicators, bar graphs, charts and vectors are not form fields; `DevicePanelFeed` gives each a `LiveDisplayViewModel` and feeds them from the contribution's structured presenter (found in the session tab's catalog), posting to the UI thread that opened the panel; `MainWindow` shows them above the form with `LiveDisplayView`.

The shell lists the contributed `IDevicePanelContribution` panels (`DevicePanels`) as buttons; `OpenDevicePanelCommand` is enabled when `DevicePanels.UnavailableReason` allows it for the selected session (connected, suitable transport, presenter selected) and shows the panel in the main area. `PanelViewModel` now disposes what it owns, so closing a panel detaches the surface subscription.

Tests: `SurfacePanelBuilderTests` (3 Unit: displays dropped, toggle and choice sends, button send) and `DevicePanelTests` (1 Unit: a connected session opens the panel and a toggle reaches the surface) and `DevicePanelFeedTests` (1 Unit: a published value updates the indicator and disposing detaches and releases the surface); WPF test project 34 passed. Confirm messages are honoured: `IConfirmPrompt` (ViewModels, `WpfConfirmPrompt` message box in `UiDefinitions.Wpf`) is passed through `FormViewModel`, `ControlViewModelFactory` and `ButtonViewModel` to `InvokeCommand` (3 Unit tests in `InvokeCommandConfirmTests`, ViewModels test project 56 passed, plus a shell test where a declined confirm sends nothing; WPF test project 35 passed). Colour buttons work through the shell's `IColorPicker` (a pick writes `R,G,B` to the target field, which sends it to the surface; one shell test; WPF test project 36 passed). Not yet done: command preview tooltips, `EnabledWhen` interlocks, notes; the XAML was not viewed running.
