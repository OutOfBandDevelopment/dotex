# Changes 2026-11-19

Work finished on 2026-11-19, one section per task. Index: [README](README.md).

## Harness test for the lease-before-inspect order

- `IntegrationContainersTests.Ensure_TakesTheLeaseBeforeLookingAtTheContainerAsync`: the process lease file exists before the first Docker inspect, so a process finishing its tests cannot stop a container this one is about to use. `OoBDev.TestUtilities.Tests` 14 passed.

## Refreshable option lists for form choice rows

- `ChoiceControl.OptionsSource` keeps the `[FormField(OptionsFrom)]` property name; `FormBinding.GetOptions` reads it; `ChoiceViewModel` re-reads it on every refresh and replaces its options and `OptionItems` (now an observable collection), so a list that changes while the form is open (detected serial ports) updates. A fixed list is unchanged. First prerequisite for putting the WPF Connection Editor on the generated form (the other two, object-valued picks and scan command properties, stay in the [spec](../applications/devterm/specs/connection-editor.md) and `BACKLOG.md`). `OoBDev.UiDefinitions.ViewModels.Tests` 68, `OoBDev.UiDefinitions.Tests` 197 and `OoBDev.UiDefinitions.Wpf.Tests` 14 passed (generator test extended, four new tests).
- Also: the per-test timing of the Integration run is recorded in `BACKLOG.md` (container start-up and the CPU embedding tests dominate, not the test bodies).

## Object-valued choice rows

- A choice row whose property holds an object (the detected LXI, BLE, HID and USBTMC devices of the Connection Editor) shows each source item by its `Display` text (`FormBinding.Format` reads a string `Display` property) and writes the picked item itself into the model (`SetText` finds it in the `OptionsSource` list). Second prerequisite for the generated WPF Connection Editor; the scan command properties stay in `BACKLOG.md`. The committed DevTerm schemas gained the `OptionsSource` property (`--write-schemas`). `OoBDev.UiDefinitions.ViewModels.Tests` 69, `OoBDev.UiDefinitions.Tests` 197, `OoBDev.DevTerm.Core.Tests` 1109 and `OoBDev.DevTerm.Tui.Tests` 418 passed (1 skipped).

## Scan commands on the connection editor model

- `ConnectionEditorViewModel` now owns `ScanLxiCommand`, `ScanBleCommand` and `ExploreBleCommand` (annotated `[FormField]` buttons in the TCP and BLE sections; scanners injectable through the constructor), so the generated form carries the scan buttons. The Tui drops them from its form (each picker already has a Detect dialog), the BLE section order moved after MQTT explicitly, and the WPF field-coverage test leaves the `*Command` fields to `ConnectionDeviceScans` until the XAML is replaced. Third prerequisite for the generated WPF Connection Editor; the ComboBox template and the rebinding remain. `OoBDev.DevTerm.Core.Tests` 1110, the Tui `ConfigureModeTests` 35 and the WPF `ConnectionEditor` tests 14 passed.

## Drop-down lists in the WPF form view

- `UiDefinitionsWpf.FormView` draws a `ChoiceStyle.Dropdown` row as a `ComboBox` when its list can change while the form is open (`OptionsSource`) or is longer than six options (`ChoiceViewModel.UsesDropdown`, two-way `PickedOption`); short fixed lists stay radio buttons, so existing panel screenshots do not change. Fourth prerequisite for the generated WPF Connection Editor. `OoBDev.UiDefinitions.ViewModels.Tests` 71, `OoBDev.UiDefinitions.Wpf.Tests` 14, `OoBDev.DevTerm.Wpf.Tests` 219 passed; the committed guide screenshots are unchanged.
