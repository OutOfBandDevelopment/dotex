## Example app: Toolbox pipeline builder

- `POST api/Toolbox/pipeline` runs text through up to 20 byte transforms (`ToolboxPipeline`: hex, base64, base32, gzip and their reverses, SHA-256, SHA-512, reverse) and returns the bytes after every step; `GET api/Toolbox/pipeline/steps` lists the keys. Bad input or an unknown step is a 400 problem, and output is capped at 1,000,000 bytes (a gunzip bomb is refused). The Toolbox page has the builder (step picker, add, clear, run, results table). 8 Unit tests in `ToolboxPipelineTests` and one vitest (14 pass, vue-tsc clean).
