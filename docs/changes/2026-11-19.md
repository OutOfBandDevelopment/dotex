Design: [ComplexEvents](../design/ComplexEvents/README.md).

## Data loader EF Core row sink

- `OoBDev.DataLoader.EntityFrameworkCore`: `EfRowSink` (dataset + key, skip/replace/fail, JSON columns), `LoadedRowsDbContext`, `TryAddEntityFrameworkRowSink`. 3 Simulate tests on SQLite, including a CSV load through the loader. Design: [DataLoader](../design/DataLoader/README.md).

## Complex events hosted schedule runner

- `OoBDev.ComplexEvents.Hosting`: `ScheduleHost` (PeriodicTimer poll, lease, complete, log and retry), `ScheduleHostOptions`, `TryAddScheduleHosting`. 3 unit tests with `FakeTimeProvider`. Design: [ComplexEvents](../design/ComplexEvents/README.md).

## File inventory CLI

- `OoBDev.FileInventory.Cli` (`file-inventory scan --root`): scans, confirms duplicates with SHA-512 and prints the groups; exit 0 none, 1 duplicates, 2 error. 3 unit tests. Design: [FileInventory](../design/FileInventory/README.md).

## File inventory image phase

- `OoBDev.IO.Inventory.Images`: dHash perceptual hash and `NearDuplicateFinder` (single-linkage groups by Hamming distance, unreadable files skipped). 3 unit tests. Design: [FileInventory](../design/FileInventory/README.md).
