## Hybrid logical clock in OoBDev.System

- `OoBDev.System.Time.HybridLogicalClock` and `HybridLogicalClockGenerator` (`Next`, `Merge`, optional max drift, `TimeProvider`, thread safe, overflow throws), derived from the sync-mesh clock with a drift guard and checked counter. 12 unit tests with fake time pass. Documented in `README.System.md`.

## CsvWriter and IniFile in OoBDev.System.IO

- `CsvWriter` (`WriteAsCsvTo`, `WriteAsCsvToAsync` with cancellation; quoted fields, invariant culture, stream left open) and `IniFile` (managed, cross-platform, case-insensitive, keeps comments and other lines) replace the proving-grounds HandyClasses versions, which used the Win32 profile API and reflection with no culture handling. 19 unit tests pass. Documented in `README.System.md`; removed from the harvest candidates and migration plan.
