# Changes 2026-11-20

Work finished on 2026-11-20, one section per task. Index: [README](README.md).

## Network discovery moved to OoBDev.System.Net.Discovery

Owner Q25 and the migration plan: the probes (`NetworkDiscovery`, mDNS, SSDP, USR bridge, UDP seam, DNS message) moved with `git mv` from `OoBDev.DevTerm.Core` to the new Framework library [OoBDev.System.Net.Discovery](../../src/Framework/OoBDev.System.Net.Discovery/README.System.Net.Discovery.md); the 9 tests moved to `OoBDev.System.Net.Discovery.Tests` and pass. DevTerm Core, Tui and Web build against the new namespace; DevTerm Core Unit tests: 1104 passed, 1 failed (`CommittedSchemas_MatchWhatTheModelGenerates`: the committed `device-manifest.schema.json` is stale, which also fails without this change; logged in the backlog). Not done: the `LxiDiscovery` probe adapter.

## Desktop OAuth client library (Q2, first slice)

`OoBDev.Security.OAuthClient.Abstractions` and `OoBDev.Security.OAuthClient` with a test project: PKCE S256 (RFC 7636 vector), discovery, loopback receiver that ignores wrong state and other paths, device code polling with `slow_down`, refresh keeping the old refresh token, revocation on sign-out, `TokenCache` with one shared refresh, `BearerTokenHandler` retry after 401, `FileSecretStore`. 16 Unit tests pass. Left: the Windows DPAPI store leaf and Keycloak Integration tests (BACKLOG).

The spike became `OoBDev.System.Sandbox` (frame protocol, grants, broker, host, pool, packages), `.Windows` (AppContainer and job object), `.Linux` (bubblewrap), `.MacOS` (Seatbelt) and `.Plugin` (entry point), with contracts in `OoBDev.System.Abstractions/Sandbox` and `ISandboxLauncher` implemented per platform and registered with `Add<Os>Sandbox(pluginAssembly)`.
