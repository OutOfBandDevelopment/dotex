# DevTerm WPF theme builder (2026-10-30)

A **Build theme...** button in the shell runs the two-step flow of dev-term. `ThemeSeedPickerWindow` (`ThemeSeedPickerViewModel`) lists Light, Dark, System and the saved user themes, takes the new theme's name, and deletes a saved theme after a confirmation (built-in themes are refused). `ThemeBuilderWindow` (`ThemeBuilderDialogViewModel` over `ThemeBuilderState`) lists every colour role with a marker for roles overridden from the seed, edits a colour through `IColorPicker`, resets a role to the seed, picks the chart palette, shows the first three contrast warnings, and previews every change live with `ActiveTheme.Preview`. Save validates the name (`ProfileName.IsValid`, reserved built-in names), asks before overwriting, writes the theme file, reloads the catalog and selects the theme. The shell cancels the preview when the builder closes. The seam is `IThemeBuilderDialog` with `WpfThemeBuilderDialog`; the user themes directory can be redirected for tests.

- Tests (`ThemeBuilderDialogTests`): seed choice and default name, nothing selected, built-in delete refused, a picked colour marking the role, reserved name, saving a new theme, a cancelled flow, and the shell opening the builder on a copy. The WPF test project has 64 Unit tests passing.
