Communications tests 52 pass; SES Unit tests 20 pass. Not run: the SES Moto Integration test (no Docker stack started; it failed with a socket error).

## Template localisation

- `LocalizedTemplateEngine` decorates `ITemplateEngine` and resolves `name.{culture}`, then the parent culture, then `name`. 4 new Unit tests (they set the thread UI culture, so the class is not parallelised). Not registered automatically; versioning is still open.

## Escape closes every dialog window

- `ManifestEditorWindow` was the only dialog without a cancel button; it now has a Close button (`IsCancel`). `XamlAccessibilityTests.DialogWindows_CloseOnEscape` requires one on every window except `MainWindow`. Tab order and shortcut tests are still open.

## Example API actions carry rights

- Owner decision 2026-11-16: the 18 open actions of `OoBDev.Example.WebApi` now sit under class-level `[ApplicationRight]` (`ai.invoke`, `cache.manage`, `operations.read`, `toolbox.use`); the `admin` role maps to them in `appsettings.json`, and `EndpointRightCoverageTests` lost its `KnownOpen` list (any unprotected action fails). Example WebApi Unit tests 56 pass. Not checked: the example web UI and its e2e journeys against the now-protected endpoints (they may need a signed-in admin).

## Vector store delete and re-embed helper

- Owner decision 2026-11-16: `IVectorStore.DeleteAsync(IEnumerable<string> ids)` (unknown ids ignored) added to the interface and implemented in the in-memory example store (ids now come from a counter, so they stay unique after a delete), SQL Server (by `VectorID` within the collection), Qdrant (point ids; `StoreVectorsAsync` now returns the generated ids instead of an empty array), Azure AI Search and pgvector (by item id), plus the wrapper. `EmbeddingVersion.ReembedAsync` stores the new tagged row first, then deletes the stale one. Search Unit 58, Example WebApi Unit 57, Pg 8, Qdrant 2 and Azure AI Search 13 pass. Not run: the SQL Server, Qdrant and pgvector Integration paths for delete (no Docker stack started), so those three implementations are covered by build and the SQL text check only.
