## BLE round-trip Hardware tests through an HC-08 (2026-11-05)

`OoBDev.System.IO.Bluetooth.Windows.Tests` (`Hc08BleRoundTripTests`, `Hardware`, `Ble`, `Serial`) talks to an SH-HC-08 module on `HC08_SERIAL_PORT` (COM4): AT commands on the serial side, then the Windows BLE transport connects to the module (found by the address `AT+ADDR?` reports), writes over BLE and reads the bytes from COM4, and the reverse as notifications. All three pass, three runs in a row. The tests found a real fault: `WindowsBleConnection` released its handles without turning the notification subscription off, so a one-central peripheral stayed linked and refused the next connection. Disconnect and dispose now write the subscription off first. The module is named `DE-5000`, so it can also stand in for that meter's BLE side when the DE-5000 BLE transport test is written.
