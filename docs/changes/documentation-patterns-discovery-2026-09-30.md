### Spike findings (summary)

- `ILanguageModelProvider` has no implementation in the repository, so replacing it is cheap.
- `Microsoft.Extensions.AI` and `.Abstractions` must be pinned to the same version (mixing 10.5.2 and 10.0.1 gives `TypeLoadException`).
- RAG methods are prompt templates and belong in a service over `IChatClient`.
- Recommendation: accept the migration. Full steps are in [the spike report](../patterns-discovery/08-spikes/01-extensions-ai.md).

### Owner directives recorded

- Abstractions projects that are only interfaces and models need no tests; abstractions with real implementation get a test library.
- Missing readmes are created, not just warned about.
- All .NET libraries should be updated for .NET 10 as far as possible, with central package management restored (not started; tracked in `TODO.md`).
- Microsoft.Extensions.AI migration is expected to be accepted.
