## Scalar sign-in restored on the named OpenAPI documents (2026-11-09)

`/scalar` offered no login because `ConfigureOAuthOpenApiOptions` was a plain `IConfigureOptions<OpenApiOptions>`, which runs only for the unnamed options, while every document is named (`all` and one per assembly), so the `oauth2` security scheme never reached them (`/openapi/all.json` had no `securitySchemes`). It is now an `IConfigureNamedOptions<OpenApiOptions>`. Verified: `ConfigureOAuthOpenApiOptionsTests` fails without the change and passes with it; the AspNetCore test project passes 34 of 34. Not verified: the running AppHost API was not restarted, so the sign-in button on `/scalar` is unchecked.
