# 2026-10-28

## Z-Wave: live switch test

- Added `RealHardwareZStickTests.Switch_AgainstRealNode_TogglesAndRestores`: it sends Binary Switch Get to the node named by the `RealSerialZStickS2SwitchNode` run parameter (`devterm.runsettings`, node 2), flips the switch, confirms the node's report, and always restores the original state. It is Inconclusive without that parameter or the port.
- Verified on the real stick (COM13) and node 2 (GE 45603 plug-in module): the outlet was on, went off (`Binary Switch Report off`), then back on; the user confirmed the physical light followed both changes.
- `RealHardwareZStickTests` is now `[DoNotParallelize]`: its three tests share one COM port and failed when run at the same time.
- `Enumerate_AgainstRealStick_ListsTheNodes` asserted the old `node 1;` text, which went stale when the Nodes table was aligned; it now checks for `Static Controller`.
- Docs: the z-wave-support proposal, `docs/specs/zwave-panel.md`, `BACKLOG.md` and `OPEN_QUESTIONS.md` now list switching as verified.
