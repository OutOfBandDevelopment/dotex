# oobdev-documentconverter

Converts a document from one format to another.

## Options

Run the tool with `--help` to list its options.

```console
$ oobdev-documentconverter --help
oobdev-documentconverter - Converts a document from one format to another.
Pass options as --name value (a boolean needs an explicit true or false).
  --input   <string>
  --output  <string>
```
