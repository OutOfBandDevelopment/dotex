# OoBDev.SpatialServices

Implementations over the [abstractions](../OoBDev.SpatialServices.Abstractions/README.SpatialServices.Abstractions.md). Today: `GeoMath`, great-circle `DistanceMeters` (haversine), `BearingDegrees` and `Destination` on a spherical Earth (mean radius 6,371,008.8 m, about 0.5 percent off an ellipsoid). Pure functions, no I/O, no DI registration. Design: [SpatialServices](../../../docs/design/SpatialServices/README.md).
