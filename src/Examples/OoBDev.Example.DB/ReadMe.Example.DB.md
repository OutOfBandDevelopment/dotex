# OoBDev.Example.DB

Example SQL Server database project demonstrating vector database capabilities.

## Description

This is an example SQL Server database project (DacPac) that demonstrates the usage of OoBDev.Data.Vectors.DB for vector-based semantic search and similarity operations. It includes reference implementations and sample schemas.

## Key Features

- Example vector database schema
- SQL CLR function demonstrations
- Service Broker integration examples
- Reference for implementing vector databases
- Pre-configured deployment settings

## Installation

This is an example project for reference purposes. To use it:

```bash
dotnet build
dotnet publish
```

## Configuration

Database deployment is configured in the .csproj file:
- Server: 127.0.0.1:1433
- Database: ExampleDb
- Authentication: SQL Authentication (sa/L0c@lD3v)

Update these settings in the .csproj file for your environment.
